# Messi Evolution: Performance vs Media Narrative

## Project Overview
This project analyzes Lionel Messi's performance across his career and compares it with media narratives before and after Argentina won the 2022 FIFA World Cup.
The goal is to understand whether Messi's greatness appeared only after winning the World Cup, or if the data shows that his elite performance existed long before Qatar 2022.

## Research Question
Did Messi's performance significantly change after the 2022 World Cup, or did the biggest change occur in public and media perception?

## Data
Two datasets were used:
**1. Messi Performance Data**
- Season
- Matches
- Goals
- Assists
- Minutes played

From these variables we created:
- Goal contribution (goals + assists)
- Goals per match
- Assists per match
- Goal involvement per match

**2. Media Headlines Dataset**
A curated dataset of headlines about Messi labeled with:
- sentiment (positive / neutral / negative)
- period (Pre-Qatar / Post-Qatar)

## Methodology
1. Data cleaning and preprocessing
2. Feature engineering
3. Aggregation by season
4. Performance evolution analysis
5. Pre vs Post Qatar comparison
6. Media narrative analysis

## Key Visualizations
The analysis includes:
- Goals by season
- Assists by season
- Goal contribution by season
- Goal involvement per match
- Performance comparison (Pre vs Post Qatar)
- Media sentiment analysis

The **2022 World Cup is clearly marked in the plots** to highlight the before/after comparison.

## Key Insight
The data shows that Messi's performance was already elite long before the 2022 World Cup.
However, the media narrative around him changed significantly after Argentina won the tournament.


## Conclusion
The World Cup did not create Messi's greatness.
It confirmed it.
